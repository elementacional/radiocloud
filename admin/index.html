1. Conta Google e sincronização

Desconectado

Escopo: drive.file. O ID do cliente fica salvo neste navegador; o token de acesso não. Após atualizar a página, use “Conectar Google” novamente. O Google pode permitir a seleção rápida da conta.

Contas Google Drive

Conecte cada conta separadamente usando o mesmo Client ID Web. As permissões de cada conta são independentes. Tokens permanecem somente na memória do navegador; depois do F5 é preciso reconectar as contas para tocar arquivos privados delas.

Nenhuma conta autorizada nesta sessão.

2. Enviar MP3 ao Google Drive

Destino: CloudRadio / Musicas / [Gênero] / [Artista] / [Álbum]; índice em CloudRadio/catalogo.json. Arquivos privados, sem publicação automática.

Pastas e gêneros musicais

Crie gêneros e envie faixas para artista e álbum; mantenha artista e álbum em branco para guardar MP3 diretamente no gênero. “Sincronizar pastas” encontra arquivos acessíveis nas pastas criadas pelo aplicativo. Para arquivos colocados manualmente no Drive, o escopo drive.file não garante acesso: envie pelo aplicativo ou importe arquivos com autorização apropriada.

6. Publicação do player Web

O Drive continua privado. Para permitir audição pública, publique apenas cópias das músicas que você tem autorização para distribuir. O GitHub Pages serve os MP3 enviados à pasta audio/ (adequado para teste pequeno, não para streaming em escala).

Abrir player Web ↗

Passos: (1) escolha a música, clique em baixar MP3; (2) envie esse MP3 sem renomear para audio/ no GitHub; (3) exporte e publique catalogo-publico.json na raiz. Repita para as demais músicas. Não publique faixas sem direitos de distribuição.
