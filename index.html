Gerenciador de MP3 · Google Drive · Fontes externas

1. Conectar Google Drive

Se abriu o HTML com caminho C:\, o catálogo funciona localmente, mas o login Google exige um site HTTPS ou localhost autorizado no Google Cloud. Não tente autenticar pelo arquivo local.

Configure um OAuth Client ID do tipo Aplicativo Web no Google Cloud. Publique esta página em HTTPS, no domínio cadastrado em Origens JavaScript autorizadas. Nunca informe um Client Secret neste HTML.

Desconectado

Permissão solicitada: drive.file. O token fica somente em memória e não é salvo no catálogo, no HTML ou no armazenamento local.

2. Enviar MP3 para a pasta CloudRadio

Após o upload confirmado, os MP3 ficam no seu Google Drive, dentro da pasta CloudRadio / Musicas. Os arquivos e o catálogo são privados por padrão. Não são publicados automaticamente para ouvintes.

3. Adicionar músicas de outras nuvens

Links de páginas (Happy Shrimp, 4shared etc.) são referências: só os links diretos de áudio podem ser testados no player. Não há captura automática de áudio de plataformas.
